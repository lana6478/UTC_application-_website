Custom Cyberdeck

A 3D-printed case housing a Raspberry Pi 5, a compact keyboard, a battery pack, and a Flipper Zero for extra functionality. Originally ran Raspberry Pi OS, later moved to a stable Linux distro. I use it as a portable penetration-testing device for my home network.

HardwareNetworking

Custom NAS

A self-configured TrueNAS server running two 4TB drives in a mirrored array for redundancy. Originally built to store music from friends' studio sessions, it now works as a full network file server and media host for anyone on the network.

HardwareElectronics

High Voltage Transformer

Built from parts sourced on AliExpress: a low-power voltage transformer, a handful of capacitors and resistors, and spare wiring. Using a diagram I found online, I soldered the components into a voltage-multiplier circuit that steps up and outputs high voltage across two wires.
